# YouTube Lyrics — локальное расширение Chrome

Расширение показывает текст текущей песни в отдельной панели поверх YouTube и YouTube Music.

## Установка

1. Откройте `chrome://extensions`.
2. Включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение**.
4. Выберите папку `MusicLyricsYouTube`.
5. Закрепите значок расширения на панели Chrome.

## Использование

1. Откройте видео на YouTube или YouTube Music.
2. Нажмите значок расширения или `⌘⇧L` на macOS (`Ctrl+Shift+L` на Windows/Linux).
3. Расширение определит исполнителя и песню, затем покажет текст.
4. Если определение ошиблось, исправьте запрос в формате `Исполнитель — Песня` и нажмите **Найти**.

Повторное нажатие на значок скрывает панель. При переходе к следующему видео открытая панель обновляется автоматически.

## Источник текста

Используется публичный API `lyrics.ovh`. В код расширения не встроены ключи или сторонние исполняемые скрипты.
